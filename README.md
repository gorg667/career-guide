# The 2027 CS/CE Career Guide

A comprehensive, data-driven guide to the best careers for a student enrolling in a
Computer Science or Computer Engineering major in the United States in September 2027.

**Final deliverable:** [`CS_CE_Career_Guide_2027.md`](CS_CE_Career_Guide_2027.md) — ~36,600 words, 13 sections.

## What's inside
1. The landscape 2022–2026 and three scenarios for 2031
2. A seven-dimension framework for scoring any tech career
3. Tier 1 careers (AI/ML, security, semiconductors, infrastructure, robotics/embedded, data engineering) — full profiles
4. Tier 2 careers (FDE, defense, quantum, health, fintech/quant, energy, PM, enterprise cloud, graphics, devtools)
5. Tier 3, niche, and contrarian paths — including the honest take on web development
6. CS vs. CE: which degree for which career
7. Year-by-year roadmap, Summer 2027 → May 2031, keyed to the recruiting calendar
8. Skills, portfolio, open source, competitions, certifications, interviews, grad school, scholarships
9. Geography, compensation, employer types, clearances, immigration
10. Master scorecard (28 careers), decision matrix, comp table, major map, scenario stress test
11. FAQ, myths, risks and hedges
12. Sources (26 primary sources with URLs) and how to keep the guide current

## Structure
- `sections/` — the guide, written section by section
- `research/` — research notes and sources
- `build.sh` — concatenates `sections/*.md` into the final MD
- `HANDOFF.md` — progress log (for continuation if the writing process is interrupted)
- `OUTLINE.md` — master outline

## Build
```bash
bash build.sh
```
